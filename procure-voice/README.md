# procure-voice

> Honest, plain-English procurement writing. The meta-skill that makes the others sound human.

## What it does

Rewrites or guides the writing of procurement content to be:
- **Direct** (the recommendation up front, not buried)
- **Specific** (numbers, names, deadlines — not "significant opportunities")
- **Jargon-free** (no "leverage", "best-in-class", "drive value", "going forward")
- **Concise** (one idea per sentence, lead with the point)
- **Honest** (no false urgency, no fake certainty, no performative hedging)

Apply it to:
- Outputs from the other procurement skills (they're already voice-aware, but this enforces it)
- Executive summaries and board updates
- Negotiation correspondence
- Internal stakeholder emails
- Spend analyses and category strategies
- Any procurement writing where someone has to read it and do something

## When NOT to use it

- Inside contract clauses (legal precision matters more than tone)
- Regulatory submissions (follow the regulator's register)
- When the user explicitly wants formal corporate tone

## How it works

It's a tone overlay, not a content skill. The other procurement skills already follow procure-voice principles. This skill exists to:
1. Make those principles explicit and consultable
2. Rewrite existing content when asked
3. Anchor the house style of the procurement skills package
